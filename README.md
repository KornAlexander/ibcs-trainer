# IBCS Trainer

A browser platformer that teaches IBCS chart rules level by level. Stomp the badly-designed charts, collect the correct IBCS notation.

Play: https://kornalexander.github.io/ibcs-trainer/

Part of [Actionable Reporting](https://actionablereporting.com). Also runs as a Rayfin app hosted in Microsoft Fabric, where every play-through is automatically saved to a typed GameStats entity.
